# L-SATS · 레이저 스캔 기반 슬래브 두께 현황 산출

여러 층의 레이저 스캔 그리드 데이터와 통합 CAD 도면(DXF)을 한꺼번에 받아 **층별·측정점별 슬래브 두께 현황**을 계산하고,
**측정점 위치도·Excel 결과표·DXF 도면**으로 출력하는 웹 프로그램입니다. 통과/미달 판정은 하지 않고 현황과 검토가 필요한 점을 보여 줍니다.
**Windows PC**에서 실행합니다.

```
   8F 바닥 (콘크리트 윗면)   ← 상부층 스캔 floor_z
 ████████████████████████    ← 슬래브
   7F 천장                   ← 하부층 스캔 ceiling_z

   두께(mm) = (상부층 floor_z − 하부층 ceiling_z) × 1000
```

---

## 0. 가장 쉬운 실행 방법 (프로그램을 몰라도 됩니다)

Python 설치 없이 **받고 → 압축 풀고 → 더블클릭**만 하면 됩니다.

1. **[여기를 눌러 L-SATS-windows.zip 받기](https://github.com/kuri-dev9/L-SATS/releases/latest/download/L-SATS-windows.zip)** (약 150~200MB)
2. 받은 파일을 **마우스 오른쪽 클릭 → 「압축 풀기」(또는 「모두 압축 풀기」) → 「압축 풀기」**
   - 바탕화면처럼 평범한 곳에 풀어 주세요. ZIP 파일 안에서 바로 실행하면 안 됩니다.
3. 풀린 `L-SATS` 폴더 안의 **`START.bat`을 더블클릭**
   - 「Windows의 PC 보호」 파란 창이 뜨면 **「추가 정보」 → 「실행」** 을 누릅니다.
4. 10~30초 뒤 브라우저에 프로그램이 열립니다. **검은 창은 사용하는 동안 닫지 마세요.** 끝낼 때 닫으면 됩니다.

처음 열면 **홈** 화면이 나옵니다. 「새 분석 시작」을 누르고 도면(DXF) 1개와 스캔 파일(CSV) 2개를 올리면 됩니다. 분석은 자동으로 **작업 내역**에 저장되어 다음에 다시 열 수 있습니다.

### 새 버전으로 업데이트 (큰 ZIP을 다시 받지 않아도 됩니다)

1. `L-SATS` 폴더 안의 **`UPDATE.bat`을 더블클릭**합니다.
2. 최신 프로그램 파일(1MB 안팎)만 받아서 바꿔 줍니다. 켜져 있던 프로그램은 알아서 닫고, 다 바꾸면 **새 버전으로 다시 띄웁니다**(v0.6.1부터. 그 전 버전에서 처음 한 번은 검은 창을 먼저 닫고, 끝나면 `START.bat`을 직접 실행하세요).

- 이미 최신이면 「Already up to date」라고 나오고 아무것도 바꾸지 않습니다.
- 바꾸기 전 파일은 `backup` 폴더에 남겨 둡니다. 작업 내역(`work_history` 폴더)과 설정(`user_settings.json`)은 그대로 남습니다.
- 새 버전이 Python 패키지까지 바꿔야 하는 경우에는 작은 업데이트로 안 되므로, 전체 ZIP 받는 페이지를 자동으로 열어 줍니다. 그때만 위 1~4번을 다시 하면 됩니다.
- `git clone`으로 받은 폴더는 `run.bat`만 실행하면 됩니다. 실행할 때마다 새 버전이 있는지 보고, 있으면 받아서(`git pull`) 필요한 패키지를 설치한 뒤 새 버전으로 띄웁니다. 그 폴더 맨 위의 `UPDATE.bat`을 더블클릭해도 같습니다(뒤에서 실행·브라우저 열기).
- `UPDATE.bat`은 v0.1.5부터 들어 있습니다. 그 전 버전을 쓰고 있다면 전체 ZIP을 한 번만 다시 받아 주세요.

> 아래 1장 이후는 Python을 직접 설치해서 실행하거나 프로그램을 고치려는 분을 위한 내용입니다.

## 1. Windows에서 실행하기 (Python 직접 설치)

### 1-1. Python 설치 (처음 한 번)

1. https://www.python.org/downloads/windows/ 에서 **Python 3.11 이상**(권장 3.13)의 *Windows installer (64-bit)* 를 받습니다.
2. 설치 첫 화면에서 **`Add python.exe to PATH`를 반드시 체크**하고 *Install Now*를 누릅니다.

### 1-2. 프로그램 받기

- **Git이 있으면:**
  ```bat
  git clone https://github.com/kuri-dev9/L-SATS.git
  ```
- **Git이 없으면:** 저장소 페이지에서 **Code → Download ZIP**으로 받아 압축을 풉니다.

### 1-3. 실행

폴더 안의 **`run.bat`을 더블클릭**합니다.

- 처음 한 번은 필요한 패키지를 설치하느라 1~3분 걸립니다. 인터넷 연결이 필요합니다.
- 설치가 끝나면 브라우저에 `http://localhost:8501`이 자동으로 열립니다.
- 끝내려면 검은 명령 창을 닫습니다.

창 없이 뒤에서 돌리고 관리하려면 (명령 프롬프트에서, macOS·Linux 는 `./run.sh` 로 같은 명령):

```bat
run.bat start      :: 뒤에서 실행하고 브라우저 열기 (이미 돌고 있으면 그대로 둠)
run.bat status     :: 돌고 있는지 확인
run.bat stop       :: 끄기
run.bat restart    :: 껐다 다시 켜기 (git pull 뒤 등)
run.bat log        :: 서버 기록 마지막 줄 보기 (.run\server.log)
```

포트를 바꾸려면 `set LSATS_PORT=8502` 뒤에 실행합니다. `start` 뒤에 붙인 옵션은 Streamlit 에 넘어갑니다 (`run.bat start --server.address 0.0.0.0`).

명령 프롬프트에서 직접 실행할 때 (`run.bat`과 같은 동작):

```bat
cd L-SATS
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py
```

> PowerShell에서 `Activate.ps1` 실행이 막히는 경우가 많습니다. 위처럼 `.venv\Scripts\python.exe`를 직접 호출하면 활성화 없이 실행됩니다.

### 1-4. 같은 사무실의 다른 PC에서 접속

```bat
run.bat --server.address 0.0.0.0
```

다른 PC 브라우저에서 `http://<실행 중인 PC의 IP>:8501`로 접속합니다. Windows 방화벽 허용 창이 뜨면 *허용*을 누릅니다.

### 1-5. 문제 해결

| 증상 | 해결 |
|---|---|
| `START.bat`이 바로 꺼짐 / `"python" folder is missing` | ZIP 안에서 실행한 경우입니다. 0장의 2번대로 압축을 먼저 푸세요 |
| 「Windows의 PC 보호」 창 | 「추가 정보」 → 「실행」 |
| `Python 3.11 or later is required` | 1-1대로 Python을 설치하고 `Add python.exe to PATH`를 체크했는지 확인 |
| 실행하면 Microsoft Store가 열림 | Windows의 가짜 `python` 바로가기입니다. 1-1대로 python.org 설치본을 설치하세요 |
| `Installation failed` | 인터넷·회사 프록시 확인 후 다시 실행. 계속 실패하면 `.venv` 폴더를 지우고 다시 실행 |
| 브라우저가 안 열림 | 브라우저에서 `http://localhost:8501` 직접 입력 |
| `Port 8501 is already in use` | 이미 실행 중입니다. `run.bat status`로 확인하고 `run.bat restart`로 다시 켜거나, `set LSATS_PORT=8502` 후 실행 |
| 위치도의 한글이 □로 보임 | Windows는 맑은 고딕을 자동으로 씁니다. Linux 서버라면 `sudo apt install fonts-nanum` |

## 2. 사용 방법

왼쪽 메뉴는 **홈 · 두께 분석 · 보고서·내려받기 · 작업 내역 · 설정**(맨 아래) 순서입니다.

| 메뉴 | 하는 일 |
|---|---|
| **홈** | 측정 원리 그림, 사용 순서, 작업 통계, **최근 분석** 목록. 줄을 누르면 그 작업이 열립니다. |
| **두께 분석** | ① 파일 올리기(여러 층의 스캔 CSV·엑셀과 DXF를 한꺼번에, 또는 폴더 통째로. 파일 안의 바닥 높이로 층을 찾아 위층부터 나열) → ② 층별 현황(층마다 평균·최소·최대, 검토·미산출 점 수, 층별 평균 막대그래프) → ③ 층 보기(콤보박스·위층/아래층 버튼으로 층 이동, **측정점 위치도**가 메인 / 서브: 방별 두께도·방별 표·3D) → ④ 다음 할 일(이 층 엑셀, 전체 층 ZIP, 보고서). |
| **보고서·내려받기** | 전체 층: 요약 엑셀, 층별 엑셀·DXF를 묶은 ZIP. 층별: 층을 골라 간단/상세 보고서를 미리 보고 HTML(→ PDF)·엑셀·DXF·CSV·ZIP을 받습니다. |
| **LAS 변환** | 층마다 하나씩 있는 레이저 스캔 점군(LAS·LAZ, 1GB 넘어도 됨)을 PC 폴더에서 바로 읽습니다. ① 폴더 고르기(「폴더 선택」을 누르면 Windows 탐색기·Mac Finder 폴더 선택 창이 뜸, 경로 붙여넣기도 됨. 마지막 폴더를 기억) → ② 그 폴더의 LAS·LAZ 중 변환할 파일 체크(모두 선택/해제, 하위 폴더 포함 가능, 층 이름 고치기) → ③ 변환(모든 층 같은 격자) → ④ 결과(층별 요약, 격자점 높이 표·그림, 「두께 분석으로 보내기」) → ⑤ 저장(**층마다 파일 / 하나의 파일**, CSV·엑셀·**DXF 평면도**(곧은 벽·격자점과 높이, 화면에서 미리보기), 폴더에 저장 또는 ZIP 내려받기). 화면 없이는 `LAS_TO_GRID.bat`에 폴더를 끌어다 놓습니다. (미리보기 모드에선 숨김) |
| **방 배치** | LAS 변환 결과에 방을 정합니다. ① 벽 위치로 층을 구조별로 자동 묶고(구조가 다르면 표에서 고치기·새 구조 추가) → ② 구조마다 방을 자동 초안 / 그림에서 끌어 추가 / 표에서 이름·범위 고치기 → ③ 같은 구조의 모든 층 도면에 넣고 「두께 분석으로 보내기」(방별 결과). |
| **작업 내역** | 저장된 분석(여러 층 한 묶음)을 찾고, 열고, 작업 이름·동·메모를 표에서 바로 고치고, 지웁니다. |
| **설정** | 계산·출력 설정(대응 거리, TIN, 단위, 결과 상태 기준, 세대 규칙, 두께 색 막대, 엑셀·보고서 구성). 맨 아래 「미리보기 모드」. |

- **측정점 위치도** 쓰는 법: 휠로 확대·축소(가장 축소 = 도면 전체 + 여백 30%, 가장 확대 = 가장 작은 방 하나), 끌어서 이동(도면 밖으로는 안 나감),
  **Shift+끌기** 또는 오른쪽 위 **나침반 끌기**로 회전(↺/↻ 1°·90° 버튼, `[` `]` 키). 기본은 CAD 도면 방향, 「북쪽 위」는 측량 좌표 방향.
  점을 누르면 그 옆에 상세 카드(두께·상태·위/아래층 Z·사용한 하부점·거리·기준면 편차·이 방 평균)가 뜹니다. 점 글자는 「글자 끄기 / 두께 / 번호+두께」.
  회전·글자·점 카드는 그림 안에서만 바뀌어 화면이 다시 그려지지 않고, 아래 방별 두께도도 같은 각도로 돌아갑니다.
- 분석은 계산되는 순간 자동 저장됩니다(`work_history` 폴더). 「새 분석」을 누르면 이전 작업은 그대로 두고, 새로 올린 파일은 (같은 파일이어도) 새 작업으로 쌓입니다.
  프로그램을 다시 켜면 마지막 작업이 자동으로 열립니다. 작업마다 그때 쓴 설정을 함께 저장하므로 나중에 열어도 결과가 같습니다. 설정을 바꾼 뒤 옛 작업을 열면 「지금 설정으로 다시 계산」 버튼이 나옵니다.
- 브라우저 주소에 작업 번호(`?job=…`)가 붙어 있어 새로고침해도 같은 작업이 열립니다.

두께 분석 화면 맨 아래 **「자세히 보기」** 는 담당자용입니다. 보통은 건드리지 않아도 됩니다.

| 탭 | 내용 |
|---|---|
| 포인트별 결과 | 측정점마다 두께·산출방법·결과 상태·미산출 사유·검토 메모, 방별 상세 통계 |
| 검토·미산출 점 | 두께 범위·이상치·하한 이하 점과 두께를 못 구한 점 (0mm로 채우지 않음) |
| 층·도면 고치기 | 층 이름(파일 이름에서 찾은 값)과 층마다 쓸 도면(자동·없음·직접 고르기) |
| 방 이름 고치기 | 도면의 방 이름이 틀렸거나 비어 있을 때(예: `실_08`) 새 이름 입력 (그 도면을 쓰는 모든 층에 반영) |
| 입력 열·설정 | 방 경계 레이어, 도면↔측량 좌표 맞춤 결과, 입력 파일 열 지정(모든 스캔 공통), 계산 설정 요약 |

### 결과 파일

| 파일 | 내용 |
|---|---|
| 보고서 (`…_간단보고서.html` / `…_상세보고서.html`) | 층별 보고서. 간단: 두께 현황·측정점 위치도(메인)·방별 두께도(서브)·검토가 필요한 점·검토 의견·확인란. 상세: 여기에 방별 현황 표·두께 분포·측정·계산 방법·부록(전체 측정점 표). 「인쇄 / PDF로 저장」 버튼으로 A4 PDF를 만듭니다. |
| 층별 Excel (`101동_8F-7F_슬래브두께.xlsx`) | 받은 결과 양식: `슬라브 두께 결과`(제목·위치별 두께 분포도·40행부터 세대·구역명/실명/포인트 ID/X/Y/두께/산출 방식/결과 상태/미산출 사유) + `포인트 위치도`(점마다 `P013 / 338mm`, 40%로 열림) + `방별 두께도`(서브). 「전체」 구성이면 `방별 현황`·`계산 상세`·`설정·요약`도 들어갑니다. |
| 전체 층 요약 Excel | `층별 요약`(층마다 평균·최소·최대·상태별 점 수, 계산 못 한 층의 이유) + `방별 현황(전체 층)` |
| DXF | 원본 도면 + 결과 레이어 `두께_산출`, `두께_검토`, `두께_미산출`, `두께_영역외`, `두께_실평균` |
| ZIP | 전체 층: 요약 엑셀 + `층별/` 폴더에 층마다 엑셀·DXF. 층 하나: 보고서·엑셀·DXF·CSV |
| CSV | 포인트별 결과 (Excel에서 열리는 UTF-8 BOM) |

### 명령줄 실행 (화면 없이 일괄 처리)

```bat
.venv\Scripts\python.exe -m slab demo_data\grid_analysis_floor_level_8F.csv demo_data\grid_analysis_floor_level_7F.csv ^
  --cad demo_data\report_merge_8F.dxf -o 결과.xlsx --dxf-output 결과.dxf ^
  --dong 101동 --upper-floor 8F --lower-floor 7F
```

옵션: `--method auto|nearest|interpolate` (없으면 설정 화면에 저장한 값). 전체 옵션은 `python -m slab -h`로 볼 수 있습니다.

## 3. 입력 파일

### 3-1. 상부층 / 하부층 스캔 (CSV, XLSX)

`grid_analysis_floor_level_*.csv` 형식을 기본으로 읽습니다. 열 이름이 다르면 화면의 **열 매핑**에서 지정합니다.
CSV 인코딩은 UTF-8과 CP949(한글 Excel 저장)를 모두 지원합니다.

| 열 | 의미 | 필수 |
|---|---|---|
| `point_id` | 포인트 번호 (층마다 따로 매겨짐) | |
| `x`, `y` | 측량 좌표 (m). 상·하부층이 **같은 측량 기준점** | ✔ |
| `floor_z` | 바닥 높이 (m), **콘크리트 윗면**. 상부층 값 사용 | ✔ (상부층) |
| `ceiling_z` | 천장 높이 (m). 하부층 값 사용 | ✔ (하부층) |
| `floor_error`, `ceiling_error` | 층 기준면 대비 편차 (m). 없으면 층 중앙값 대비 편차로 계산 | |
| `has_floor`, `has_ceiling`, `is_empty` | 측정 유무 플래그 | |

### 3-2. 통합 CAD (DXF)

| 요소 | 조건 |
|---|---|
| 실 경계 | 닫힌 폴리라인 (기본 레이어 `ROOM_BOUNDARY`, 화면에서 변경 가능) |
| 실명 | 실 경계 **안쪽**의 TEXT/MTEXT, 실 경계와 **같은 레이어** (예: `8호_거실`) |
| 측정점 라벨 | 상부층 포인트 번호 문자(`P001`…)와 원(CIRCLE). **3개 이상** 필요 |

측정점 라벨은 도면 좌표(mm, 회전 없음)를 측량 좌표(m, 회전됨)로 맞추는 기준점으로 씁니다.
도면이 이미 측량 좌표로 그려져 있다면 라벨이 없어도 됩니다.

## 4. 계산 방법

1. **대응점 매칭.** 상·하부층은 같은 측량 기준점을 쓰지만 **격자 배치와 포인트 번호가 층마다 다릅니다.**
   예를 들어 같은 위치가 8F에서는 `P001`, 7F에서는 `P007`입니다. 그래서 **번호가 아니라 XY 좌표**로 대응시킵니다.
   - **직접 대응 우선 → 실패 시 TIN**(기본): 위층 격자 교차점에서 가장 가까운 아래층 격자 교차점이 허용 거리(기본 1.2 m, 1.5 m 격자 기준) 안에 있고 정상 천장점이면 그 값을 쓰고,
     없으면 주변 하부점 세 개로 만든 삼각형(TIN)에서 보간합니다. 삼각형 밖은 **외삽하지 않고 미산출**로 남깁니다.
     TIN에 쓴 세 점의 번호·좌표·높이·가중치는 포인트 결과에 함께 남습니다.
   - **직접 대응만** / **TIN 보간만**도 설정 페이지에서 고를 수 있습니다.
   - 하부점 하나를 여러 상부점에 쓸지(재사용), 가까운 쌍부터 1:1로 배정할지도 설정으로 정합니다.
   - 좌표·높이 단위(m/mm)는 자동으로 판단합니다. 한 파일 안에서 단위가 섞이면 멈추고 알려 줍니다.
2. **두께.** `(floor_z − ceiling_z) × 1000` mm
3. **결과 상태.** 측정점마다 아래 상태 중 하나를 붙입니다 (받은 결과 엑셀과 같은 이름·기준, **설정 페이지**에서 바꿀 수 있음).
   통과/미달 판정은 하지 않습니다.

   | 결과 상태 | 기준 (기본값) | 두께 값 |
   |---|---|---|
   | 영역 외 | 도면의 방 경계 밖 | 비움 |
   | 미산출 · 대응점 없음 | 아래층에 같은 위치 점이 없고 TIN도 안 됨 (삼각형 밖·퇴화·3점 미만·너무 큰 삼각형) | 비움 (0으로 채우지 않음) |
   | 미산출 · Z값 확인 필요 | 위층 바닥 측정 없음, 또는 바닥·천장이 층 기준면에서 30 mm 넘게 벗어남 (바닥 위 물건·천장 설비 등) | 비움 (계산값은 상세에 참고로 남김) |
   | 두께 비정상(하한 이하) | 0 mm 이하 | 보임 |
   | 두께 범위 검토 | 140 mm 이상 | 보임 |
   | 이상치 검토 | 같은 방 점(5개 이상)의 중앙값에서 3.5×MAD 넘게 벗어남 | 보임 |
   | 산출 완료 | 위에 해당하지 않음 | 보임 |

4. **실 배정.** 도면의 측정점 라벨로 도면↔측량 좌표 변환(축척·회전·이동)을 최소제곱으로 구하고,
   각 점이 들어가는 실 경계를 찾습니다. 실은 도면의 **고유 실 ID**로 묶으므로 이름이 같은 다른 실은 합쳐지지 않고,
   세대 ID는 실명 앞부분(`101호_거실` → `101호`, `코아2_EV홀` → `코아2`, 그 밖은 `공용`)에서 뽑습니다.
   경계선 위 점은 그 실에 넣고, 경계가 겹친 곳의 점은 검토 메모를 남깁니다. 경계 밖의 점은 **영역외**로 따로 세고
   평균에는 넣지 않습니다.
5. **집계.** 방·층의 평균·최소·최대·표준편차는 **산출 완료** 점으로만 냅니다. 검토·미산출 점은 개수만 셉니다.
6. **여러 층.** 파일 안의 층 바닥 높이(`Global_Floor_m`, 없으면 바닥 Z 중앙값)로 층 순서를 정하고 바로 아래층과 짝짓습니다.
   위층 바닥과 아래층 천장 차이가 −0.3~1.0 m 밖이면(층이 빠짐 등) 그 층은 계산하지 않고 이유를 보여 줍니다.
   층 이름은 파일 이름의 `8F`·`B1` 표기, 없으면 순서대로 `층1`…. 도면은 위층 기준으로 파일 이름의 층에 붙이고,
   층 표기 없는 도면이 하나면 도면이 없는 모든 층에 공용, 여러 개면 측정점 번호 좌표가 맞는 층에 붙입니다.

### LAS 변환 (점군 → 격자 높이)

1. **층마다 훑기.** 높이 분포에서 점이 가장 많이 몰린 두 수평면(층고 1.8~4.5 m 간격)을 바닥면·천장면으로 잡고,
   벽 높이의 점을 여러 각도로 돌려 보아 건물 축(측량 좌표에서 기울어진 각도)을 찾습니다. 잡음 분류(7, 18) 점은 뺍니다.
2. **격자 고정.** 모든 층의 바닥면을 덮는 격자를 건물 축 방향으로 놓고(기본 간격 1.5 m) 출력 폴더의 `grid.json`에 저장합니다.
   다음에 다른 층을 변환해도 같은 격자를 씁니다(「격자 새로 정하기」를 켜면 새로).
3. **격자점 높이.** 격자점 둘레 0.4 m 정사각형 안에서 바닥면·천장면 ±0.3 m 안의 점을 모아,
   점이 가장 많이 몰린 높이(5 mm 칸, ±10 mm 평균)를 바닥 Z·천장 Z로 합니다. 벽·가구의 세로 점에 덜 끌려갑니다.
4. **결과.** `<LAS 폴더>/LSATS_grid/grid_analysis_floor_level_<층>.csv` (기존 형식 + 격자 행·열, 건물 축 좌표, 격자 정의).
   모든 층의 점 번호(`G001-001` …)와 좌표가 같아 위·아래층이 같은 위치끼리 바로 짝지어집니다.
   도면 없이도 결과 그림·엑셀이 **건물 축에 맞춰 반듯하게** 그려집니다(「북쪽 위」로 측량 방향도 볼 수 있음).

시험용 가상 점군: `python tools/make_demo_las.py [폴더]` (23.5° 기울어진 3개 층, 두께 115/125 mm).

### 설정 페이지

왼쪽 메뉴의 **설정**에서 대응 거리, TIN 조건, 단위, 결과 상태 기준(140 mm·0 mm·MAD 3.5배 등), 세대 ID 규칙,
두께 색 막대(기본 100~140 mm), 위치도 해상도, 엑셀·보고서 구성(기본: 결과 + 포인트 위치도 + 방별 두께도, '검토 전 초안' 표시)을 바꿀 수 있습니다.
저장한 값은 프로그램 폴더의 `user_settings.json`에 남아 업데이트해도 유지되고, JSON 파일로 내려받아 다른 PC에 올릴 수 있습니다.
'담당자 확인 필요'가 붙은 항목은 기본값이 아직 확정되지 않은 값입니다.

설정 맨 아래 **미리보기 모드**를 켜면 초창기 버전처럼 꾸밈 없는 화면(메뉴 `main / rpt / cfg`, 주소 `pg_rpt_v01` 등,
고정 그림·영문 표, 확대·회전·3D·안내 문구 없음)으로 바뀝니다. 계산·작업 저장·보고서·엑셀은 같은 코드라 결과 파일은 똑같습니다.
이 값은 작업마다 저장하는 계산 설정과 따로 `user_settings.json`의 `ui` 항목에 바로 저장됩니다. 끄려면 `cfg` 맨 아래에서 끕니다.

### 데모 데이터

저장소에는 실제 현장 데이터가 들어 있지 않습니다. 대신 `tools/make_demo_data.py`로 만든 **가상 데이터**가
`demo_data/`에 있습니다. 실제 데이터와 같은 형식이고, 실제처럼 층마다 격자 위치·포인트 번호가 어긋나 있으며,
바닥 위 물체·천장 설비 같은 이상값도 섞여 있습니다.

데모 데이터는 테스트용이며 화면에 자동으로 뜨지 않습니다. 직접 올려서 써 볼 수 있습니다.

| 항목 | 값 (기본 설정: 직접 대응 우선 → TIN) |
|---|---|
| 구성 | 2세대 8실 (`실_08`은 실명 문자가 없는 경계 → 실명 편집 예시) |
| 포인트 | 상부층 58점. 두께가 131~148 mm라 140 mm 이상 점은 '두께 범위 검토'로 나옵니다 |
| 이상값 | 바닥 위 물체·천장 설비 → 미산출(Z값 확인 필요), 아래층에 대응점 없는 점 → 미산출(대응점 없음) |
| 도면 정합 | 회전 23.5°, 잔차 RMS 0.4 mm |

데모 데이터를 다시 만들려면 `.venv\Scripts\python.exe tools\make_demo_data.py`를 실행합니다. 결과는 항상 같습니다.

실제 현장 데이터는 공개 저장소에 올리지 마세요. 로컬 `sample_data/` 폴더는 `.gitignore`에 들어 있어 커밋되지 않습니다.
