L-SATS - Slab Thickness Analyzer

[How to start]
1. Double-click START.bat
2. If "Windows protected your PC" appears: click "More info" -> "Run anyway"
3. The browser opens http://localhost:8501 automatically (about 10-30 seconds)
4. Keep the black window open while using the program. Close it to stop.

[How to update]
1. Close the black START.bat window if the program is running.
2. Double-click UPDATE.bat. It downloads only the program files (about 1 MB).
3. When it says "Updated", double-click START.bat again.
   Old files are kept in the "backup" folder.
   If the new version needs new packages, UPDATE.bat opens the full ZIP download page instead.

[Notes]
- Do not move START.bat out of this folder. The "python" folder must be next to it.
- Extract to a normal folder such as Desktop or C:\L-SATS (not inside the ZIP, not Program Files).
- Menu (left): Home / Thickness analysis / Report / Job history / Settings.
- Upload the scan files (CSV/Excel) and drawings (DXF) of many floors at once, or a whole folder.
- LAS point clouds (one file per floor, 1 GB+): use menu "LAS" in the program and type the folder path,
  or drag and drop the LAS folder onto LAS_TO_GRID.bat. The same grid is used for every floor (grid.json).
  The CSV files are written to the "LSATS_grid" folder next to the LAS files.
- Every analysis is saved automatically in the "work_history" folder and can be reopened from Home or Job history.
  "New analysis" keeps the old job; the last job opens again when the program restarts.
- Settings are saved in "user_settings.json". UPDATE.bat keeps both work_history and user_settings.json.
- To move to another PC, copy the work_history folder and user_settings.json too.
